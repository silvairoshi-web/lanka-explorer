# API Notes — Week 04
- Weather: Open-Meteo current forecast endpoint; no API key required. Network/CORS or service failures show a fallback message.
- Currency: Frankfurter latest USD→LKR endpoint; the My Trip page keeps totals visible and reports conversion as unavailable if the request fails.
- Map: OpenStreetMap embedded map; internet connection is required.
- Coordinates are approximate destination locations. API services may change availability.
