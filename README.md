## Project Description

Lanka Explorer is a web application designed to help travellers
discover and explore interesting destinations across Sri Lanka.
The website provides information about heritage sites, beaches,
nature destinations and wildlife locations.

## Destinations

The project features 10 destinations from Sri Lanka covering
four main categories: Heritage, Beach, Nature and Wildlife.

### Heritage

1. Sigiriya Rock Fortress
2. Galle Fort
3. Anuradhapura

### Beach

4. Mirissa Beach
5. Unawatuna Beach
6. Arugam Bay

### Nature

7. Ella
8. Nuwara Eliya

### Wildlife

9. Yala National Park
10. Minneriya National Park
